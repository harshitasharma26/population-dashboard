🌏 India Population Dashboard
An interactive data dashboard built with Python and Streamlit to explore population, literacy rate, sex ratio and growth rate across 640 districts and 28 states of India.
🔗 Live Demo
   https://populationdashboard.streamlit.app/
📌 About the Project
The goal was to make India's population data easy to explore through interactive charts and filters — without needing to look at raw numbers in a spreadsheet.
This project covers everything from data cleaning to building a multi page interactive dashboard with three sections — Home, State Analysis and District Analysis.
📊 Pages and Features :

🏠 Home Page
Welcome introduction to the dashboard
3 key metrics — total districts, total states and total population
Bar chart showing top 5 most populated states in India
Quick links to what each section covers

📊 State Analysis Page
Multiselect to choose one or more states — all charts update automatically
Literacy Gap Chart — shows how each selected state compares to the overall average literacy rate. Green means above average, red means below
State Comparison Chart — compare selected states on population, literacy, sex ratio or growth using a dropdown selector
Quick Number Cards — key metrics for every selected state side by side

🏙️ District Analysis Page
Select any state and then any district inside it
Report Card — shows population, literacy rate, sex ratio and growth rate for the selected district
District Rankings — shows where the district ranks among all districts in the same state for population, literacy and growth
Highlighted Bar Chart — top 10 most populated districts with the selected district highlighted in red so it's easy to spot
Top 5 Literacy Districts — table showing the most literate districts in the state
Top 10 Fastest Growing Districts — bar chart showing districts with highest growth rate
